**Halan Andrade**

## 📌 Objetivo

Desenvolver um plano básico de manutenção preventiva para uma máquina industrial, com o objetivo de reduzir falhas, aumentar a vida útil dos componentes e melhorar a segurança durante a operação.

## ⚙️ Equipamento

**Máquina:** Equipamento mecânico industrial

### Principais componentes

- Motor elétrico
- Mancais e rolamentos
- Eixos
- Correias
- Polias
- Sistema de transmissão
- Elementos de fixação

## 🔧 Plano de manutenção

| Atividade | Periodicidade |
|---|---|
| Inspeção visual | Diária |
| Verificação de ruídos e vibrações | Semanal |
| Verificação das correias | Semanal |
| Lubrificação dos componentes | Mensal |
| Inspeção dos rolamentos | Mensal |
| Verificação dos elementos de fixação | Mensal |
| Inspeção geral do equipamento | Trimestral |

## 📝 Checklist

- [ ] Verificar ruídos anormais
- [ ] Verificar vibrações
- [ ] Inspecionar correias
- [ ] Conferir lubrificação
- [ ] Verificar rolamentos
- [ ] Conferir parafusos e fixações
- [ ] Verificar desgaste dos componentes
- [ ] Registrar as manutenções realizadas

## 🎯 Resultados esperados

A aplicação de um plano de manutenção preventiva pode contribuir para:

- Redução de paradas inesperadas;
- Aumento da vida útil dos componentes;
- Maior segurança operacional;
- Redução dos custos de manutenção corretiva;
- Maior confiabilidade do equipamento.

## 📚 Conhecimentos aplicados

Este projeto utiliza conhecimentos relacionados à:

- Mecânica Básica;
- Ajustagem Mecânica;
- Manutenção;
- Elementos de Máquinas;
- Desenho Técnico;
- Engenharia Mecânica.

## 📌 Conclusão

A manutenção preventiva é uma ferramenta importante para manter equipamentos em condições adequadas de funcionamento. O planejamento das inspeções e intervenções permite identificar possíveis problemas antes que ocorram falhas mais graves.
